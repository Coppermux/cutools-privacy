CuTools Privacy Policy

Effective date: 9 November 2026
Application: CuTools
Developer: Coppermux Studio (Pty) Ltd
Contact: admin@coppermux.co.za

1. Introduction

Coppermux Studio (Pty) Ltd respects your privacy.

CuTools is an Android web browser and developer-tools application that allows users to browse websites, inspect web content, examine network activity, execute JavaScript and access debugging tools directly on their Android devices.

CuTools is designed to operate locally, without requiring a user account or connection to a developer-operated cloud service.

This Privacy Policy explains how CuTools processes, stores and handles information.

2. Information Collection

CuTools does not collect or transmit personal information, browsing activity, diagnostic information or device identifiers to Coppermux Studio (Pty) Ltd.

The application does not include:

  • Advertising or advertising SDKs.
  • Analytics or behavioural tracking services.
  • Third-party crash-reporting services.
  • Developer-operated telemetry services.
  • User registration or account systems.

CuTools does not operate a remote server that receives browsing or developer-tools information.

3. Website Browsing

CuTools uses Android WebView to display websites.

When you visit a website, your device communicates directly with that website and any third-party services or resources it uses.

These communications may involve information such as your IP address, requested URLs, cookies, authentication information and other data ordinarily exchanged during web browsing.

The websites you visit are responsible for their own privacy practices.

Coppermux Studio (Pty) Ltd does not receive or independently collect this browsing information.

4. Local Data Storage

CuTools stores certain information locally on your Android device to support its functionality.

This may include:

  • Saved workspaces, website addresses and workspace settings.
  • Website cookies and browser storage.
  • Website authentication and session information managed by Android WebView.
  • Application preferences, including the floating F12 button's visibility and position.
  • Temporary console messages, network inspection data and debugging information.

Saved workspaces and application preferences remain on the device until deleted through the relevant controls or Android's application data settings.

Console messages and developer-tools inspection data are generally maintained in temporary application memory.

Website cookies and storage are managed by Android WebView and may persist between browsing sessions.

CuTools does not independently upload this information to Coppermux Studio (Pty) Ltd.

5. Developer Tools and Diagnostic Information

CuTools provides developer tools using the Chrome DevTools Protocol (CDP).

Communication between the application's developer tools and Android WebView takes place locally on the device.

The internal debugging bridge uses local connections and session authentication to restrict access.

Developer-tools information, including console output, inspected webpage content, network request details and performance information, is not transmitted to Coppermux Studio (Pty) Ltd.

Production releases do not enable CuTools' development diagnostic-tracing facility.

6. Workspace Connectivity Checks

CuTools may check the availability of websites saved in your Workspaces.

When the Workspaces screen is opened or refreshed, CuTools sends HTTP HEAD requests directly to the relevant website servers.

These requests are used to determine whether saved websites are reachable.

They are not sent to Coppermux Studio (Pty) Ltd.

The destination websites may observe these requests and process connection information according to their own privacy practices.

7. Network Security

CuTools supports both HTTPS and HTTP connections.

HTTPS provides encryption between your device and the destination server when correctly configured.

HTTP connections are not encrypted.

CuTools permits HTTP connections because inspecting local development servers and non-HTTPS endpoints is part of its intended functionality.

Users should exercise caution when transmitting sensitive information over unencrypted HTTP connections.

CuTools' internal developer-tools communication uses local device connections rather than an external debugging server.

8. Android Backup

CuTools disables Android application cloud backup and device-to-device application data transfer through its application configuration.

Saved workspace information, application preferences and browser data are not intentionally uploaded by CuTools to an external backup service.

This does not prevent websites or other applications from independently processing information exchanged with them.

9. Data Retention and Deletion

CuTools provides several controls for managing locally stored information.

Reset App: Resets the application's active interface and clears temporary developer-tools information. It does not delete saved workspaces, website cookies or persistent browser storage.

Clear Logs: Clears temporary console and diagnostic event information. It does not delete saved workspaces or website storage.

Workspace Deletion: Removes the selected saved workspace. It does not automatically delete cookies or other browser data associated with that website.

Website Storage Controls: The developer-tools storage inspector allows users to clear supported storage associated with a selected website origin.

Complete Application Data Removal: Users can delete locally stored CuTools application data through Android Settings by selecting CuTools and choosing the option to clear application storage or data.

Uninstalling CuTools also normally removes its application-private data, subject to Android's operating-system behaviour.

CuTools does not maintain a developer-operated database containing user information that requires a separate deletion request.

10. Third-Party Websites

CuTools allows users to access websites and online services operated by third parties.

These services may collect information, use cookies or apply their own tracking technologies.

Coppermux Studio (Pty) Ltd does not control the privacy practices of websites visited through CuTools.

Users should consult the privacy policies of those websites for information about their data practices.

11. Children's Privacy

CuTools is intended as a general-purpose browser and developer-tools application.

It is not specifically designed for children.

Coppermux Studio (Pty) Ltd does not knowingly collect personal information from children through CuTools.

Websites accessed through the application may have their own age restrictions and privacy requirements.

12. Changes to This Privacy Policy

Coppermux Studio (Pty) Ltd may update this Privacy Policy to reflect changes to CuTools, its functionality or applicable privacy requirements.

Updates will be published on the application's public privacy policy page.

The effective date will be updated when material changes are made.
